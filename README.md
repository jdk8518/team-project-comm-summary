# AI 문서 분석 & DB 아카이빙 웹 UI 시스템 (Gharam MVP)

`vibe-frame-kit` 프론트엔드 기능 구현 기준에 따라 **상단 탭 메뉴(파일업로드, 파일검색)를 구축하고, 파일 분석·요약·검증·아카이빙 저장 및 DB 검색·요약 수정·원본 1-Click 다운로드 기능**을 통합 제공하는 프론트엔드 시스템입니다.

---

## 1. 프론트엔드 메뉴 및 주요 구현 기능

### 📌 1) 상단 탭 메뉴 구성 (Navigation Bar)
- **`[📤 파일업로드]` 탭**:
  - 문서 파일 업로드 (PDF, DOCX, TXT, HWP, HWPX, PPTX / 최대 50MB)
  - 3단계 유효성 검증 ➔ 텍스트 파싱 ➔ AI 구조 분석 ➔ 팩트 요약 ➔ 검증 렌더링
  - 추천 저장 폴더 경로 및 재지정 파일명 수정 입력
  - **`[💾 DB 요약 및 원문 파일 저장]`** 버튼으로 원본 파일 보관 및 DB 저장
- **`[🔍 파일검색]` 탭**:
  - 저장된 문서를 키워드 / 부서 필터로 DB 실시간 검색
  - **리스트 클릭 시 요약 내용 출력**: 상세 요약 모달 창 표시
  - **수정 버튼 (`[✏️ 요약 수정하여 DB 반영]`)**: 요약 문구를 편집하여 DB 업데이트 (`PUT /api/v1/documents/{file_id}/summary`)
  - **다운로드 버튼 (`[📥 1-Click 원본 파일 다운로드]`)**: 보관된 원본 문서 바이너리 스트림 다운로드 (`GET /api/v1/documents/{file_id}/download`)

> ⛔ **MVP 제외 사항 준수**: 로그인, 분석 이력 목록(전체 히스토리 뷰어 제외 단순 검색), 다중 문서 동시 업로드 제외.

---

## 2. 서버 실행 방법

### 1) Uvicorn 서버 구동
```bash
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

### 2) 웹 UI 접속
* **웹 대시보드 메인 화면**: `http://127.0.0.1:8000`
* **Swagger API 웹문서**: `http://127.0.0.1:8000/docs`

---

## 3. 정상 처리 및 오류 처리 수동 확인 방법

### 🔵 1) 정상 처리 확인 (Happy Path)
1. **파일업로드 탭 (`[📤 파일업로드]`)**:
   - `http://127.0.0.1:8000` 접속 ➔ 문서 선택 ➔ **[AI 문서 분석 요청]** 클릭.
   - 분석 결과 확인 후 폴더/파일명 및 요약 수정 ➔ **[💾 DB 요약 및 원문 파일 저장]** 클릭.
2. **파일검색 탭 (`[🔍 파일검색]`)**:
   - 상단 **`[🔍 파일검색]`** 탭 클릭 ➔ 검색어 입력 후 **[검색]** 클릭.
   - 검색된 파일 리스트 카드 클릭 ➔ 상세 요약 모달 표출 확인.
   - 모달 내 요약 문구 수정 후 **`[✏️ 요약 수정하여 DB 반영]`** 클릭 ➔ DB 반영 성공 알림 확인.
   - **`[📥 1-Click 원본 파일 다운로드]`** 클릭 ➔ 웹 브라우저에서 원본 문서 파일 다운로드 동작 확인.

### 🔴 2) 오류 처리 확인 (Exception Path)
1. **미지원 포맷 업로드**: `.xlsx` 선택 후 요청 ➔ *"지원하지 않는 파일 형식입니다."* 오류 알림 상자 표출.
2. **검색 결과 없음**: 존재하지 않는 키워드로 검색 ➔ *"검색 조건에 해당되는 저장 문서가 없습니다."* 처리.
