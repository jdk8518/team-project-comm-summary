## 마지막 walkthrough 문서 이후 수행 작업

### 1. AI 모델 확인 방법 조사

- Codex 앱의 모델 선택기와 API 응답 JSON의 `model` 필드가 모델 확인에 사용될 수 있음을 조사했다.
- 현재 스레드 목록과 스레드 상세 정보를 확인했으나 실제 모델 ID는 노출되지 않았다.
- 현재 스레드에는 연결된 터미널 세션도 없어, 터미널을 통한 API 응답 JSON 확인은 불가능했다.
- 이 환경에서 지원 가능한 모델 목록은 확인했으나, 지원 목록은 현재 대화에 실제로 배정된 모델의 근거가 아님을 확인했다.

### 2. 토큰 사용량 확인 방법 조사

- 현재 Codex 세션의 도구 목록과 스레드 상세 조회 기능을 확인했다.
- 현재 도구에는 세션별 입력·출력·총 토큰을 직접 반환하는 기능이 없었다.
- API를 직접 호출하는 경우 응답 JSON의 `usage` 객체를 저장하는 방식이 가장 정확하다고 정리했다.
- 로컬 토크나이저 계산은 시스템 지시문, 도구 호출, 내부 추론 및 재시도를 포함하지 못하므로 추정치로만 사용해야 함을 정리했다.

### 3. walkthrough 작성 규칙 보완

- 이후 walkthrough 문서 작성 시 작업 시작 직전과 완료 직후의 시간을 기록하기로 했다.
