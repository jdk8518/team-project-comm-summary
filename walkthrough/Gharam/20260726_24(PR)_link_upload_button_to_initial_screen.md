## 1. 구현 내용

- 상단 내비게이션의 `📤 파일업로드` 버튼 클릭 동작을 업로드 탭 전환 함수 호출에서 초기 화면 경로(`/`) 이동으로 변경했습니다.
- 따라서 검색 화면이나 분석 결과 화면에서 해당 버튼을 누르면 애플리케이션의 초기 업로드 화면으로 다시 이동합니다.
