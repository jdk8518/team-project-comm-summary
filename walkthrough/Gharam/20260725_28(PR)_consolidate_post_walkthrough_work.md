## 수행 내용

### 1. 12단계 문서 관리 흐름 완성

- 검색된 문서의 DB 레코드, 아카이빙 원본 파일, 임시 업로드 파일 및 메모리 바이너리를 함께 제거하는 삭제 처리를 추가했다.
- `DELETE /api/v1/documents/{file_id}` 및 호환용 별칭 경로를 제공하고, 존재하지 않는 문서는 404로 처리한다.
- 검색 결과 상세 모달에서 삭제 확인 후 목록을 갱신하는 UI 흐름을 연결했다.

### 2. AI 호출·문서 파싱 구조 정리 및 OCR 보완

- AI 제공자 설정을 `app.core.config`로 모으고, OpenAI·Gemini 호출 공통 처리와 분석·요약·검증별 프롬프트/응답/폴백을 분리했다.
- 형식별 텍스트 추출을 TXT, PDF, DOCX, HWP/HWPX, PPTX 단위의 보조 함수로 나눴다.
- PDF에서 추출한 텍스트가 20자 미만이면 `pytesseract` 기반 OCR을 시도하고, OCR 후에도 분석 가능한 텍스트가 없으면 기존 422 오류 계약을 유지한다.
- OCR 의존성으로 `pytesseract`, `Pillow`를 추가했다. 실제 OCR 실행에는 운영 환경의 Tesseract 엔진 및 필요 언어 데이터 설치가 필요하다.

### 3. 아카이빙 경로 이동·추천과 폴더 탐색

- `PUT /api/v1/documents/{file_id}/folder`에서 대상 폴더를 생성하고 원본 파일을 이동한 뒤 저장 경로 메타데이터를 갱신하도록 구현했다.
- `GET /api/v1/documents/{file_id}/recommend-folder`에서 문서의 부서·조직·핵심 개념을 바탕으로 실존 아카이브 폴더의 상위 3개 후보를 반환하도록 구현했다.
- `GET /api/v1/documents/folder-tree`와 검색의 `folder` 필터를 추가해 폴더 중심 탐색을 지원한다.
- 검색 결과 모달에서 현재 경로를 편집하고, 추천 경로를 선택해 파일 이동을 실행할 수 있도록 화면을 확장했다.

## 변경 파일

- `app/db.py`: 삭제·이동 처리, 아카이브 폴더 목록 및 폴더 트리 생성을 추가했다.

- `app/schemas.py`: 이동 및 폴더 추천 요청·응답 DTO를 추가했다.

- `tests/test_api.py`: 삭제, 이동, 폴더 추천, 존재하지 않는 문서 오류 경로 테스트를 보강했다.

## 입력과 출력

- 입력: 업로드된 문서의 `file_id`, 이동할 `new_folder_path` 및 선택적 `new_filename`, 또는 저장된 문서의 요약 키워드와 기존 아카이브 폴더 목록.
- 출력: 삭제 성공 여부, 이전·새 파일 경로, 폴더 추천 목록, 폴더 계층 및 폴더별 검색 결과.
- 오류 처리: 존재하지 않는 문서 삭제·이동은 404, 파일 이동 실패는 400, 추출 가능한 텍스트가 없는 문서는 422를 반환한다.

## 다른 기능과의 연결

- 업로드·분석·요약·검증·저장으로 이어지는 기존 MVP 흐름의 저장 이후 단계를 삭제·이동·탐색 기능이 확장한다.
- OCR은 PDF 텍스트 추출 단계에만 폴백으로 연결되며, 기존 텍스트 기반 문서 처리 및 API 응답 형식은 유지한다.
- 폴더 추천은 LLM을 호출하지 않는 키워드 규칙 기반 로직으로, AI 분석 결과의 키워드를 입력으로 사용한다.

## 공통 구조에 미치는 영향

- 기존 API와 DTO는 유지하면서 엔드포인트와 DTO를 추가했다.
- AI 설정 및 호출 중복을 `app.core`와 공통 서비스 함수로 분리해 향후 제공자 확장 지점을 한곳으로 모았다.
- 현재 저장소의 DB는 인메모리 구현이므로, 삭제·이동 상태는 프로세스 재시작 후 유지되지 않는 기존 제약을 따른다.

## 남아 있는 문제

- 테스트 실행을 위해 사용할 Python 인터프리터와 프로젝트 의존성 환경을 설정해야 한다.
- OCR 품질 검증과 이미지 전용 PDF 회귀 테스트는 Tesseract 및 한국어 언어 데이터가 준비된 환경에서 추가 확인이 필요하다.
- 경로 이동은 지정한 파일 시스템 경로에 쓰기 권한이 있어야 하며, 운영 환경에서는 허용 경로 제한을 별도로 검토할 필요가 있다.
