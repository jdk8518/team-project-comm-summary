## 수행 내용

파일 저장 시 원본 경로의 확장자를 `.md`로 바꾼 sidecar 경로를 계산하고, 문서 개요·목적·주요 내용·결론·검증 상태를 Markdown으로 기록하도록 `app/db.py`에 구현했다. 분석·요약·검증 단계의 오류 메시지가 있으면 Markdown에도 함께 표시한다.

요약 내용이 수정되면 이미 저장된 sidecar를 즉시 다시 작성한다. 원본 파일을 다른 폴더로 이동하면 동일한 이름의 Markdown 파일도 함께 이동하고, 삭제 시 원본과 Markdown sidecar를 모두 삭제한다. 파일 저장 응답과 DB 레코드에는 기존 원본 경로를 유지하고, 내부적으로 `summary_path`를 관리한다.

## 남아 있는 문제

동시 저장 요청에 대한 순번 경쟁 조건은 기존 파일 생성 정책과 동일하게 남아 있다. 운영 환경에서는 DB unique 제약 또는 파일 생성 재시도 로직을 추가로 고려해야 한다. 기존 무관 문서 변경은 보존했다.
