## 작업 지시사항 원문

> 사용자가 PDF, DOCX, HWP, HWPX, PPTX 또는 TXT 문서 한 개를 업로드하면 서비스가 문서 본문을 추출하고 AI 분석·요약·검증을 수행한다. 사용자는 결과 화면에서 문서 핵심 요약, 주요 키워드, 검증 결과와 확인 필요 항목을 확인할 수 있다. 지원하지 않는 파일이나 분석할 내용이 없는 문서를 입력하면 처리를 중단하고 오류 안내를 제공한다. 사용자가 요약 화면을 확인하고 저장하면 DB에 저장한다. 사용자가 DB에 저장된 내용을 검색하고 선택하면 요약화면(파일 다운로드 경로 포함)을 제공한다. 검색요약 화면에서 수정하여 요약 내용을 수정할 수 있도록 한다. README의 실행 방법에 따라 로컬 환경에서 서비스를 실행할 수 있다.

## 1. 수행 내용

제시해주신 최종 **MVP 서비스 종합 동작 시나리오 및 완료 기준(Definition of Done, DoD)**을 수용하고, 전체 시스템 파이프라인과 로드맵의 최종 기준으로 확정 등록했습니다.

1. **핵심 기능 파이프라인 확정**:
   - 6종 포맷(PDF, DOCX, HWP, HWPX, PPTX, TXT) 단일 파일 업로드 및 본문 텍스트 자동 추출
   - AI Agent 기반 핵심 구조 분석, 3단 요약, 교차 검증 및 검증 신뢰도/인간 검토 항목 생성
   - 결과 화면 시각화 출력 (메타데이터, 요약, 키워드, 검증 배지, 4대 검토 리스트)
2. **예외 처리 및 흐름 차단 확정**:
   - 미지원 확장자/포맷 입력 또는 파싱 후 텍스트 미존재(0자/스캔본) 시 AI 파이프라인 진입을 즉시 중단하고 명확한 오류 안내 메시지 표출
3. **DB 저장, 검색 및 원본 다운로드/수정 흐름 확정**:
   - 사용자가 요약 화면을 최종 확인하고 [저장] 실행 시 DB 저장 처리
   - DB 저장 목록 검색 및 선택 시 요약 상세 화면(원본 파일 다운로드 경로 포함) 제공
   - 검색 요약 화면 내에서 사용자가 직접 요약 내용을 수정하고 저장할 수 있는 기능 확정
4. **로컬 실행 보장 기준 확정**:
   - `README.md`의 실행 방법 및 가이드에 따라 로컬 환경에서 백엔드/프론트엔드 서비스를 손쉽게 구동하고 시연할 수 있도록 보장
