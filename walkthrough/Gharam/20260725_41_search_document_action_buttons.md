## 수행 내용

검색 결과 카드에 `수정`, `MD`, `원본` 액션 버튼을 추가했다. `수정`은 기존 상세 요약 편집 모달을 호출하고, `MD`는 저장된 `.md` sidecar를 조회하는 `/api/v1/documents/{file_id}/markdown`을 새 탭에서 열며, `원본`은 기존 원본 다운로드 API를 호출한다. 버튼 이벤트는 카드 자체의 선택 이벤트와 분리해 독립적으로 동작하도록 구성했다.

검색 화면의 기존 우측 상세 요약 패널은 초기 화면에서 숨겼고, 검색 결과를 렌더링할 때 자동으로 상세 정보를 조회하지 않도록 변경했다. 따라서 상세 요약은 문서 카드의 `수정` 버튼을 누른 경우에만 팝업으로 활성화된다.

입력은 검색 결과의 문서 ID다. 출력은 요약 편집 팝업, 새 탭의 Markdown 응답, 원본 파일 다운로드다. 저장되지 않은 문서에 MD를 요청하면 404 오류를 반환한다.

## 다른 기능과 연결할 부분

MD 버튼은 이전 작업에서 생성한 `summary_path` sidecar를 사용하고, 원본 버튼은 기존 다운로드 API를 사용한다. 수정 모달에서 요약을 저장하면 sidecar도 기존 DB 업데이트 경로를 통해 갱신된다.

## 공통 구조에 미치는 영향

검색 프론트엔드와 Markdown 조회 API만 변경했다. 기존 폴더 트리·검색 조건·원본 다운로드·요약 수정 데이터 구조는 유지했다.

## 남아 있는 문제

기존 우측 상세 패널 관련 JavaScript 함수는 레거시 호환을 위해 남아 있지만 검색 카드에서는 더 이상 자동 호출하지 않는다. 추후 팝업 편집 흐름을 단일 컴포넌트로 정리할 수 있다. 기존 무관 문서 변경은 보존했다.
