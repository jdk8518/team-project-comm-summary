## 수행 내용

검색 결과 카드 본문 클릭으로 열리는 Markdown 뷰어를 화면 영역 전체 모드로 변경했다. 뷰어 상단에 `수정`, `다운로드`, `닫기` 버튼을 배치하고 현재 문서 ID를 저장해 각 동작을 연결했다. `수정`은 뷰어를 닫고 기존 상세 요약 편집 팝업을 열며, `다운로드`는 해당 문서의 원본 다운로드 API를 호출한다. `닫기`는 검색 탭으로 돌아가 문서 목록을 새로 고친다.

## 변경한 파일

## 입력과 출력

입력은 검색 결과 카드의 문서 ID다. 카드 클릭 시 Markdown sidecar를 렌더링한 전체 화면 뷰어가 출력되고, 상단 버튼으로 편집 팝업 열기·원본 다운로드·검색 목록 복귀를 수행한다.
