## 1. 수행 내용

1. **처리 불가 파일(미지원 포맷) 감지 및 분류 엔진 구축 (`static/index.html`)**:
   - 단일 파일/다중 파일/폴더 전체 선택 및 드래그 앤 드롭 업로드 시 프로젝트 지원 포맷(`PDF`, `DOCX`, `TXT`, `HWP`, `HWPX`, `PPTX`)이 아닌 파일을 자동으로 감지하여 `unsupportedFileList` 리스트로 분류하도록 구현했습니다.
2. **화면 맨 하단 카드 UI 표출 (`static/index.html`)**:
   - 업로드 탭(`[📤 파일업로드]`) 맨 하단에 `⚠️ 처리 불가 파일 리스트 (지원하지 않는 포맷)` 카드를 신설했습니다.
   - **표시 항목 4가지 100% 구현**:
     1. `원본저장경로`: 폴더 업로드 시 하위 상위 경로(`webkitRelativePath`) 또는 파일 저장 폴더 경로 표출
     2. `파일명`: 미지원 포맷 파일명 (경고 아이콘 `⚠️` 및 분홍색 뱃지)
     3. `작성일시`: 파일의 최종 수정/작성 일시 (`YYYY-MM-DD HH:mm:ss`)
     4. `파일크기`: 포맷팅된 파일 용량 (예: `1.2 MB`, `450.5 KB`)
3. **목록 비우기 기능 추가**:
   - `🧹 목록 비우기` 버튼을 배치하여 사용자가 확인한 미지원 파일 리스트를 손쉽게 초기화할 수 있도록 구현했습니다.
