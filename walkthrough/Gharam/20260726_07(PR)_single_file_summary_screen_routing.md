## 1. 수행 내용

1. **단일 파일(1개) 처리 시 기존 요약 화면 라우팅 연동 (`static/index.html`)**:
   - 파일 선택, 폴더 선택, 드래그 앤 드롭 등 유효 포맷 파일 수집 결과 지원 가능한 파일이 **1개**인 경우, 다중 파일 자동 작업리스트로 보내지 않고 기존의 **메인 요약 리포트 화면 (`#resultSection`)**을 출력하도록 라우팅을 개편했습니다.
   - 단일 파일 파이프라인 분석(`POST /api/v1/documents/analyze`)이 실행되며, 화면에 기존의 문서 기본 정보, 추천 저장 경로/파일명/소속부서, 핵심 요약 리포트, 5대 키워드, AI 검증 상태, 필수 체크리스트 카드가 즉시 출력됩니다.
2. **검토 및 저장 플로우 연동**:
   - 사용자가 기존과 동일하게 요약 내용과 부서/저장 경로를 직접 검토·수정한 후 `💾 DB 요약 및 원문 파일 저장` (`submitSave()`) 버튼을 눌러 확정 저장(`user_confirmed=True`)하도록 플로우를 완비했습니다.
3. **2개 이상 다중 파일 처리 흐름 유지**:
   - 수집된 유효 파일이 **2개 이상**인 경우에만 다중 파일 파이프라인(`POST /api/v1/documents/analyze-auto`)이 작동하며, 하단 `📋 다중파일 작업리스트`로 수집됩니다.
