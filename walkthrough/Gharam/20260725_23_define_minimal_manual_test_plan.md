## 1. 수행 내용

확정된 MVP 완료 기준(DoD) 및 종합 서비스 시나리오를 바탕으로, 실무자가 로컬 환경에서 직접 손쉽게 검증할 수 있는 **최소 수동 확인 및 테스트 가이드(Minimal Manual Test Plan)**를 수립했습니다.

1. **정상 흐름 수동 확인 시나리오 (Happy Path Verification)**:
   - `TC-01`: 로컬 서비스 구동 및 메인 화면 접속 확인
   - `TC-02`: 정상 문서(6종) 업로드 및 AI 파이프라인(분석, 3단 요약, 신뢰도 배지, 체크리스트) 동작 확인
   - `TC-03`: 4대 인간 검토 항목 체크 및 DB 저장 실행 확인
   - `TC-04`: DB 검색, 선택 요약 미리보기/수정 및 원본 1-Click 다운로드 스트림 확인
2. **예외 및 오류 안내 수동 확인 시나리오 (Exception Verification)**:
   - `TC-05`: 미지원 확장자(`.xlsx`, `.zip` 등) 차단 및 알림 메시지 확인
   - `TC-06`: 50MB 초과 대용량 파일 수신 거부 및 안내 메시지 확인
   - `TC-07`: 0자 빈 파일 또는 스캔 이미지 문서 감지 및 OCR 안내 처리 확인
3. **테스트 제외 범위 명시**:
   - 단일 시연 환경 전제에 따른 부하/성능 테스트, 복잡한 Auth 보안 테스트, K8s 배포 테스트 제외 사유 명시
