# 요구사항 정의서

## 1. 프로젝트 개요

- 프로젝트명: AI Agent를 활용한 문서 분석 시스템
- 목적: 회의록, 업무보고서, 공문 등 업무 문서를 업로드하면 AI가 핵심 내용을 요약하고, 문서 내용에 대한 검증 결과를 제공한다.
- 대상 사용자: 회의 및 업무 문서를 빠르게 검토해야 하는 일반 사무직 사용자와 프로젝트 관리자
- 문제 정의: 긴 업무 문서에서 핵심 결정 사항, 요청 사항, 일정, 담당자를 직접 찾고 검토하는 데 시간이 오래 걸리며, 누락이나 모순을 확인하기 어렵다.

## 2. 서비스 목표

사용자가 문서를 올린 뒤 다음 결과를 한 화면 또는 API 응답으로 받을 수 있어야 한다.

1. 문서에서 추출한 원문 텍스트
2. 문서 유형에 맞춘 핵심 요약
3. 주요 항목별 검증 결과와 근거
4. 처리 실패 시 원인과 재시도 방법

초기 MVP에서는 단일 문서 분석 흐름을 안정적으로 제공하는 것을 목표로 하며, 사용자 계정, 데이터베이스 저장, 관리자 기능은 범위에서 제외한다.

## 3. 사용자 시나리오

1. 사용자가 분석할 업무 문서 파일을 선택해 업로드한다.
2. 시스템은 파일 형식과 크기를 확인한 뒤 문서에서 텍스트를 추출한다.
3. AI 분석 흐름은 추출된 텍스트를 바탕으로 문서 요약과 검증 결과를 생성한다.
4. 사용자는 요약, 검증 항목, 검증 근거 및 경고 사항을 확인한다.
5. 지원하지 않는 파일, 손상된 파일, 텍스트를 추출할 수 없는 파일은 오류 메시지와 함께 처리되지 않는다.

## 4. MVP 기능 요구사항

### 4.1 문서 업로드

- 사용자는 PDF, DOCX, TXT, HWPX, PPTX 파일을 업로드할 수 있어야 한다.
- 서버는 허용된 확장자와 파일 크기를 검증해야 한다.
- HWP(v5 바이너리) 파일은 지원하지 않으며, HWPX로 변환해 업로드하도록 안내해야 한다.
- 업로드된 원본 파일은 분석 처리 용도 외에 영구 보관하지 않는 것을 기본 원칙으로 한다.

### 4.2 텍스트 추출

- 시스템은 파일 형식별 처리 도구를 이용해 본문 텍스트를 추출해야 한다.
- 추출 결과가 비어 있거나 읽을 수 없는 경우, 분석을 진행하지 않고 원인을 알려야 한다.
- HWPX는 `python-hwpx` 라이브러리를 사용해 읽는다.
- 문서 쓰기 기능이 이후 추가될 경우 원본 파일을 덮어쓰지 않고 새 경로에 저장해야 한다.

### 4.3 AI 요약

- 시스템은 추출 텍스트를 바탕으로 핵심 내용을 짧고 이해하기 쉬운 한국어로 요약해야 한다.
- 요약에는 가능한 범위에서 다음 항목을 포함한다.
  - 문서의 목적 또는 주제
  - 주요 논의·결정 사항
  - 요청·할 일
  - 일정 또는 기한
  - 담당자 또는 관련 부서
- 문서에 해당 정보가 없으면 추정하지 않고 `확인 불가`로 표시한다.

### 4.4 문서 검증

- 시스템은 문서에 포함된 필수 정보의 존재 여부를 점검해야 한다.
- 초기 검증 항목은 문서 유형과 관계없이 다음을 기본으로 한다.
  - 제목 또는 문서 주제
  - 작성일 또는 기준일
  - 주요 내용
  - 요청 사항 또는 후속 조치
  - 일정·기한 정보(있는 경우)
  - 담당자·담당 부서 정보(있는 경우)
- 각 검증 결과는 `통과`, `주의`, `확인 필요` 중 하나로 표시해야 한다.
- `주의` 또는 `확인 필요` 결과에는 판단 근거가 된 문장 또는 누락된 항목을 함께 제공해야 한다.
- AI의 결과는 보조 판단임을 명시하며, 사실 여부를 자동으로 확정하지 않는다.

### 4.5 결과 제공

- API는 분석 성공 여부, 파일 정보, 추출 텍스트, 요약, 검증 결과를 구조화된 JSON으로 반환해야 한다.
- 처리 중 오류가 발생하면 HTTP 상태 코드와 사용자에게 이해 가능한 오류 메시지를 반환해야 한다.
- 민감정보, API 키, 인증 토큰, 업로드 원문 전체를 오류 로그에 기록하지 않는다.

## 5. 비기능 요구사항

| 구분 | 요구사항 |
| --- | --- |
| 사용성 | 비개발자도 파일 업로드와 결과 확인을 수행할 수 있는 단순한 흐름을 제공한다. |
| 성능 | 일반적인 업무 문서 1건의 분석 요청은 서버 자원과 AI 응답 상태를 고려해 합리적인 시간 안에 완료되도록 구성한다. |
| 안정성 | 형식 오류, 손상 파일, 텍스트 미추출, AI 호출 실패를 구분해 처리한다. |
| 보안 | API 키와 비밀번호는 환경 변수로 관리하고, 실제 값은 코드·문서·로그에 포함하지 않는다. |
| 개인정보 | 업로드 문서의 개인정보와 기밀정보를 불필요하게 저장하거나 출력하지 않는다. |
| 확장성 | 문서 유형별 분석 규칙과 검증 항목을 이후 추가할 수 있도록 분석 단계를 분리한다. |

## 6. 기술 및 제약 사항

- 언어: Python 3
- 백엔드: FastAPI
- AI 워크플로: LangChain, LangGraph
- 문서 처리 대상: PDF, DOCX, TXT, HWPX, PPTX
- 데이터베이스: MVP 단계에서는 사용하지 않는다.
- 프런트엔드: MVP 진행 상황에 따라 별도로 결정한다.
- HWPX 처리 라이브러리: `python-hwpx` (Python 3.10 이상)

## 7. 범위 제외 항목

다음 항목은 초기 MVP에 포함하지 않는다.

- 회원가입, 로그인, 권한 관리
- 분석 이력과 원본 문서의 영구 저장
- 여러 문서 간 비교 및 통합 요약
- HWP(v5) 바이너리 파일 직접 지원
- 문서 내용을 자동으로 수정하거나 결재·발송하는 기능
- 관리자 대시보드와 고급 통계 기능

## 8. 성공 기준 및 테스트 기준

- 지원 형식의 정상 문서를 업로드하면 텍스트 추출, 요약, 검증 결과가 반환된다.
- 지원하지 않는 확장자와 손상된 파일은 분석하지 않고 오류를 반환한다.
- 텍스트가 없는 문서는 추출 실패 또는 확인 필요 상태로 안내한다.
- 요약 결과에 원문에 없는 사실을 단정적으로 추가하지 않는다.
- 검증 결과의 `주의`·`확인 필요` 항목에는 근거 또는 누락 이유가 포함된다.
- 민감한 환경 변수 값과 업로드 원문이 오류 응답 및 로그에 노출되지 않는다.

## 9. 향후 개선 방향

- 회의록, 업무보고서, 공문별 특화 요약·검증 템플릿 제공
- OCR을 통한 스캔 문서 텍스트 인식 지원
- 사용자 피드백을 반영한 요약 품질 개선
- 분석 결과 다운로드 및 이력 관리
- 문서 간 일정·담당자·결정 사항 비교 기능
