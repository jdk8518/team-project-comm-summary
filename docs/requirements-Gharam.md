# 요구사항 정의서

## 1. 프로젝트 개요
- **프로젝트명**: AI Agent를 활용한 회의록, 업무보고, 공문자료 등을 이용한 문서 분석 시스템 구축
- **한 줄 설명**: 회의록, 업무보고서, 공문 등 다양한 문서(PDF, DOCX, TXT, HWP, HWPX, PPTX)를 업로드하면 AI가 핵심 내용을 요약·검증하고, 규칙 기반 파일명/폴더 저장 및 DB 검색·원파일 다운로드를 제공하는 시스템
- **프로젝트 목적**:
  1. 문서를 업로드하면 AI가 핵심 내용을 요약하고 검증 결과를 제공한다.
  2. 문서를 사용자가 정의한 방식으로 파일 이름을 재지정하고 폴더를 구분하여 저장한다.
  3. 요약내용을 DB로 작성하고, 검색하여 요약내용을 확인하고 원본 파일을 다운받을 수 있도록 한다.

## 2. 해결하고자 하는 문제
- **현재 문제**: 회의록, 업무보고서, 공문 등 다양한 형식의 문서가 대량으로 접수되고 파편화되어 있어 주요 안건 및 정보 파악에 과도한 시간이 소요되고 중요한 정보를 누락할 위험이 존재함.
- **사용자가 겪는 불편**: 
  - 수십~수백 건의 문서를 수동으로 정독하고 일일이 요약문 및 이력을 작성하는 데 따르는 생산성 저하.
  - 파일명이 제각각으로 저장되어 있어 필요한 원본 문서를 신속하게 검색하고 다운로드하기 어려움.
  - 문서 보관 규칙에 맞춰 일일이 파일명 재지정 및 폴더 분류 작업을 수행해야 하는 번거로움.
- **이 서비스가 제공할 가치**: 
  - AI Agent를 활용해 문서 파싱, 메타데이터 추출, 구조화 요약 및 검증 신뢰도 점수를 자동화하여 검토 시간 대폭 단축.
  - 규칙 기반 자동 파일명 재지정 및 폴더 분류 저장으로 아카이빙 효율화.
  - 요약 DB 연동 검색 및 원본 파일 1-Click 다운로드 환경 제공.

## 3. 대상 사용자
- **주요 사용자**: 회의록, 업무보고서, 공문자료 등을 지속적으로 수신·검토하고 아카이빙해야 하는 공공 및 기업 실무자/관리자.
- **사용자의 상황**:
  - 주간/월간 단위로 부서별 업무보고, 회의록, 공문 등 대량의 다양한 파일(PDF, DOCX, TXT, HWP, HWPX, PPTX)이 동시에 접수되는 상황.
  - 과거 문서의 핵심 결론 및 추진 경과를 빠르게 조회해야 하는 상황.
- **사용자의 기대 결과**:
  - 업로드만으로 핵심 요약문, 키워드, 주요 수치/조건, 검증 결과(근거 위치 및 신뢰도 점수)를 한눈에 파악.
  - 정의한 명명 규칙에 따라 정돈된 저장소 관리 및 DB 검색을 통한 원본 다운로드.

## 4. 입력 데이터
- **사용자가 입력하는 데이터**:
  - 분석 대상 문서 파일 (PDF, DOCX, TXT, HWP, HWPX, PPTX)
  - 사용자 정의 파일명 재지정 규칙 (선택)
  - 저장 대상 분류 폴더 경로 (선택)
  - 문서 유형 힌트 (회의록 / 업무보고 / 공문자료 중 선택 가능)
- **필수 입력값**:
  - 문서 파일 (단일 또는 다중)
  - 지원 파일 확장자 유효성 (PDF, DOCX, TXT, HWP, HWPX, PPTX)
- **선택 입력값**:
  - 파일명 변경 규칙 패턴 및 저장 분류 폴더 위치

### 문서 유형별 세부 입력 요구사항
1. **PDF 문서 (`.pdf`)**: 텍스트 레이어 포함 파일 (스캔본 여부 및 암호 설정 체크)
2. **Word 문서 (`.docx`)**: 표준 MS Word 파일 (암호 보호 체크, 제목/스타일 구조 유지)
3. **텍스트 파일 (`.txt`)**: 일반 텍스트 파일 (인코딩 형식 UTF-8/EUC-KR 체크)
4. **HWP / HWPX 문서 (`.hwp`, `.hwpx`)**: 한글 v5 및 개방형 HWPX 문서 (배포용/암호 설정 여부 체크)
5. **PowerPoint 문서 (`.pptx`)**: MS 프레젠테이션 파일 (슬라이드 텍스트 및 프레젠터 노트 포함)

## 6. 처리 흐름
1. **사용자**: 문서 파일(PDF, DOCX, TXT, HWP, HWPX, PPTX)을 업로드하고 필요한 경우 저장/파일명 규칙을 설정합니다.
2. **시스템**: 입력 파일의 확장자, 용량, 암호 설정 여부를 검증하고 텍스트 및 메타데이터(제목, 일자, 소속)를 파싱합니다.
3. **AI Agent**: 문서 구조(배경/현황/해결책/결론)를 분류하고 핵심 키워드, 주요 수치, 결정사항을 추출하여 요약문을 생성합니다.
4. **AI Agent / 시스템**: 원문 대비 요약문 교차 검증을 통해 근거 매핑 및 신뢰도 점수를 산출하고, 규정된 파일명/폴더 구조로 저장 준비를 합니다.
5. **시스템**: 분석 및 요약 리포트, 검증 결과를 화면에 출력하고 DB에 요약 내역을 저장합니다.
6. **사용자**: 검증 결과 및 요약을 최종 확인하고 원본 파일을 다운로드하거나 지정된 폴더로 정리를 완료합니다.

## 7. 출력 결과

사용자가 문서 내용을 빠르게 이해하고 최종 검토를 수행할 수 있도록, 시스템은 분석 결과를 다음과 같이 구조화된 Markdown 리포트 형태로 화면 및 파일로 출력합니다.

### 1) 메타데이터 헤더 (Document Metadata)
- **문서 제목**: 추출 및 정제된 문서 공식 명칭
- **문서 작성 일자 및 시행 일자**: 
  - 작성일자: `YYYY-MM-DD`
  - 시행일자/수신일자: `YYYY-MM-DD` (공문자료인 경우)
- **문서 작성 소속부서(기관)**: 
  - 작성기관(발신): 소속 부처/기관/기업명
  - 작성부서: 담당 부서명 및 작성자 정보

### 2) 주요 키워드 & 핵심 요약 (Summary & Keywords)
- **주요 키워드 (Tags)**: 문서 전체의 핵심 개념 태그 5~7개 (예: `#AI분석`, `#공문자동화`, `#인프라개선`)
- **문서 핵심 요약**:
  - **한 줄 요약**: 문서 전체의 핵심 가치/결론을 한 문장으로 요약
  - **문맥별/구조별 요약**:
    - **배경 및 추진 목적**: 사업/안건의 기본 배경 및 필요성
    - **주요 현황 및 내용**: 핵심 진행 사항, 주요 일정별/안건별 세부 요약
    - **최종 결론 및 향후 계획**: 결정사항, 승인 결과 및 향후 조치 일정

### 3) 문서 검증 결과 (Validation & Evidence Mapping)
- **검증 신뢰도 점수**: `0 ~ 100점` (원문-요약문 문맥 일치도 및 환각 여부 교차 측정)
- **검증 근거 매핑 (Citation)**:
  - 요약문 각 섹션별 원문 내 근거 위치 (페이지/단락/행 번호) 표시
  - 원문 대조 매핑 UI 링크 제공
- **환각(Hallucination) 및 오류 위험 표시**:
  - 원문과 미세하게 상충되거나 추론으로 판단되는 문장에 대한 '주의' 태그 표시

### 4) 확인이 필요한 항목 목록 (Items Requiring Human Review)
사용자가 최종 승인 전 직접 눈으로 확인해야 하는 필수 검토 리스트:
- [ ] **메타데이터 정확성**: 자동 추출된 작성일자/소속부서/문서제목의 일치 여부
- [ ] **정밀 수치 및 수량 검증**: 금액, 예산, 수량, 적용 비율 등 핵심 정밀 수치 검토
- [ ] **특이 조건 및 기한 확인**: 계약 조건, 제출 기한, 승인 권한자 명시 여부
- [ ] **검증 경고 항목 확인**: 신뢰도 점수 80점 미만 항목 또는 경고 표시된 문장의 원문 직접 대조

## 8. 예외 상황 처리

시스템은 문서 분석 프로세스 중 발생할 수 있는 주요 예외 상황에 대해 다음과 같이 감지, 안내, 예외 처리를 수행해야 합니다.

### 1) 지원하지 않는 파일 형식이 업로드된 경우
- **감지 조건**: 확장자 검증 시 시스템 지원 포맷(PDF, DOCX, TXT, HWP, HWPX, PPTX)이 아닌 파일이 입력된 경우 (예: `.xlsx`, `.zip`, `.png` 등)
- **시스템 처리 및 안내**:
  - 업로드 프로세스 즉시 중단 및 해당 파일 업로드 거부
  - 안내 메시지: *"지원하지 않는 파일 형식입니다. (지원 형식: PDF, DOCX, TXT, HWP, HWPX, PPTX)"*
  - 지원 가능한 포맷 목록을 사용자 UI 툴팁/안내문으로 표시

### 2) 문서 내용이 비어 있는 경우
- **감지 조건**: 파일 파싱 완료 후 추출된 실질 텍스트 글자 수가 0자이거나 공백/특수문자만 존재하는 경우
- **시스템 처리 및 안내**:
  - AI 분석 단계로 넘어가지 않고 해당 파이프라인 즉시 중단
  - 안내 메시지: *"문서 내 분석할 수 있는 텍스트 내용이 존재하지 않습니다."*
  - PDF는 추출 텍스트가 20자 미만이면 선택적 OCR 폴백을 시도
  - Tesseract가 없거나 OCR 결과도 부족하면 분석을 중단하고 OCR 환경 확인이 필요함을 안내

### 3) AI 분석 중 오류가 발생한 경우
- **감지 조건**: LLM/AI Agent 호출 시 네트워크 타임아웃, API 할당량 초과, 컨텍스트 초과 오류 또는 비정상 응답이 발생한 경우
- **시스템 처리 및 안내**:
  - 자동 재시도(Retry) 최대 3회 수행 후 계속 실패 시 예외 처리
  - 해당 문서를 '분석 실패' 상태로 표시하고 에러 사유 요약 제공
  - 안내 메시지: *"AI 분석 처리 중 오류가 발생했습니다. 잠시 후 [재시도] 버튼을 눌러주세요."*
  - 이미 성공한 다른 다중 문서 작업에는 영향이 없도록 개별 문서 단위 독립 예외 처리

### 4) 파일 크기가 너무 큰 경우
- **감지 조건**: 업로드된 문서 파일 단일 용량이 시스템 허용 기준(예: 단일 파일 50MB)을 초과하는 경우
- **시스템 처리 및 안내**:
  - 업로드 시작 단계 또는 서버 수신 직후 용량 체크하여 수신 거부
  - 안내 메시지: *"파일 크기가 제한 용량(50MB)을 초과했습니다. 문서를 분할하거나 용량을 줄여 업로드해 주세요."*
  - 다중 업로드 시 용량 초과 파일만 선별 제외하고 정상 용량 파일은 계속 진행

## 9. MVP 범위

### MVP에 포함할 기능
- PDF, DOCX, TXT, HWP, HWPX, PPTX 포맷 문서 업로드 및 텍스트/메타데이터 파싱
- AI Agent를 활용한 회의록/업무보고/공문 핵심 요약 생성 및 키워드 추출
- 원문-요약 검증 신뢰도 점수 및 근거 위치 표시
- 요약문 화면 출력 및 원본 파일 다운로드 링크 제공
- 기본 규칙 기반 파일명 재정의 및 분류 저장
- 예외 상황(미지원 포맷, 빈 문서, AI 분석 오류, 용량 초과) 감지 및 사용자 알림 처리

### MVP에서 제외할 기능
- OCR 결과 보정, 외부 OCR 서비스 연동, 이미지·표 중심 문서의 고도화된 OCR 파이프라인
- 사용자별/부서별 미세 권한 관리 및 고도화된 대시보드 통계
- 외부 연동 자동 이메일/협업 툴 전송 기능

## 10. 추가 기능 (향후 고려 사항)
- OCR 결과 보정 및 이미지·표 중심 문서용 고도화 OCR 파이프라인 추가
- 대용량 문서 배치 처리 및 멀티모달 차트/이미지 요약 분석
- 타 시스템(전자결재, 사내 그룹웨어) API 연동

## 11. 가정 사항
- 업로드되는 문서는 암호 해제된 상태이거나 정상적인 텍스트 레이어를 포함하고 있다.
- AI Agent 동작을 위한 외부 LLM API(또는 내부 로컬 LLM) 연결 상태가 유지된다.
- HWP 문서 파싱은 `docpler`, HWPX 문서 파싱은 `python-hwpx`를 사용한다.
